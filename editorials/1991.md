**Hint 1**

**Hint 2**

Alice should always chose color 1 and 2.

**Hint 3**

**Hint 4**

Bob can color all the vertices using just 2 colors if graph is [Bipartite graph](https://en.wikipedia.org/wiki/Bipartite_graph)

**Hint 5**

Play as Bob if graph is [Bipartite graph](https://en.wikipedia.org/wiki/Bipartite_graph) and Alice otherwise.
