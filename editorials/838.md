# Hints

**A**: Let *Cost*(*k*) the answer if we compress the image with *k*, find *min* *Cost*(*k*).

**B**: Solve the problem without first query.

**C**: Let the frequencies of the characters be *a*1, *a*2, ..., *a**k*. Alice loses if and only if ![](https://espresso.codeforces.com/87a044b9d58a62a9dfe8b8482a252bce9eecfb12.png) is odd and *n* is even.

**D**: Consider adding an extra seat, and the plane is now circular.

**E**: Let *dp**i*, *j* be the longest path given that we've included segment *i*, *j* in our solution, and we are only considering points to the right of ray *i*, *j* (so *dp**i*, *j* and *dp**j*, *i* may be different).

**F**: We want to compute *dp**i*, *j*: expected value given we have seen *i* red balls and *j* black balls.
