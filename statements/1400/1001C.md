C. Generate GHZ state

time limit per test

1 second

memory limit per test

256 megabytes

input

standard input

output

standard output

You are given *N* qubits (1 ≤ *N* ≤ 8) in zero state ![](https://espresso.codeforces.com/8bb67080da7081bfb802ca6ecc5abc4f4c5ca190.png). Your task is to create Greenberger–Horne–Zeilinger (GHZ) state on them:

![](https://espresso.codeforces.com/acb08ce15c611d90dc85f731accccd9bbfac8fd3.png)

Note that for *N* = 1 and *N* = 2 GHZ state becomes states ![](https://espresso.codeforces.com/891b1e75c93e44f237b7fde497062f8e85c1d952.png) and ![](https://espresso.codeforces.com/aec27febc80bfeb882cb96d33386f048ce011703.png) from the previous tasks, respectively.

Input

You have to implement an operation which takes an array of *N* qubits as an input and has no output. The "output" of your solution is the state in which it left the input qubits.

Your code should have the following signature:

```
namespace Solution {  
    open Microsoft.Quantum.Primitive;  
    open Microsoft.Quantum.Canon;  
  
    operation Solve (qs : Qubit[]) : ()  
    {  
        body  
        {  
            // your code here  
        }  
    }  
}
```
