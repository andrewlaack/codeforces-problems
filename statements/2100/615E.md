Source: https://codeforces.com/problemset/problem/615/E

E. Hexagons

time limit per test

1 second

memory limit per test

256 megabytes

input

standard input

output

standard output

Ayrat is looking for the perfect code. He decided to start his search from an infinite field tiled by hexagons. For convenience the coordinate system is introduced, take a look at the picture to see how the coordinates of hexagon are defined:

![](https://espresso.codeforces.com/3b2337e9f4aadba64c4f33339db20ad466e772b7.png) ![](https://espresso.codeforces.com/5662ae948778adbfe5476af10bd0c1c576d7afb1.png) Ayrat is searching through the field. He started at point (0, 0) and is moving along the spiral (see second picture). Sometimes he forgets where he is now. Help Ayrat determine his location after *n* moves.

Input

The only line of the input contains integer *n* (0 ≤ *n* ≤ 1018) — the number of Ayrat's moves.

Output

Print two integers *x* and *y* — current coordinates of Ayrat coordinates.

Examples

Input

```
3
```

Output

```
-2 0
```

Input

```
7
```

Output

```
3 2
```
