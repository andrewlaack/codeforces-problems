A tree is an undirected connected graph with no cycles.

You are given a tree with $n$ nodes, rooted at node $1$. Each node $i$ ($1 \le i \le n$) has a binary state, initially equal to $x_i$ ($x_i \in \{\texttt{0},\texttt{1}\}$) and a target binary state $y_i$ ($y_i \in \{\texttt{0},\texttt{1}\}$) associated with it.

You wish to make the state of every node equal to its target state. To do so, you are allowed to inject energy pulses into the root node. Each time a pulse is injected, it propagates through the tree according to the following procedure:

* If the current state of the node is $\texttt{0}$, its state becomes $\texttt{1}$, and the pulse stops at this node.
* Otherwise, if the current state of the node is $\texttt{1}$, its state becomes $\texttt{0}$, and the node sends one pulse to each of its children. If it has no children, then the pulse disappears. Every pulse sent to a child follows the same propagation rules.

Determine whether it is possible to make the state of every node equal to its target state. If it is possible, also find the minimum number of energy pulses needed to achieve this goal. Since this number can be very large, report the answer modulo $998\,244\,353$.

Input

The first line of the input contains a single integer $t$ ($1 \le t \le 10^4$) — the number of test cases. The description of each test case follows.

The first line of each test case contains a single integer $n$ ($1 \le n \le 2 \cdot 10^5$) — the number of nodes in the tree.

The next $n-1$ lines each contain two integers $u$ and $v$ ($1 \le u,v \le n$, $u \ne v$), denoting an undirected edge between nodes $u$ and $v$. It is guaranteed that the given edges form a tree.

The next line contains a binary string $x$ of length $n$, where $x_i$ ($1 \le i \le n$, $x_i \in \{\texttt{0},\texttt{1}\}$) represents the initial state of node $i$.

The next line contains a binary string $y$ of length $n$, where $y_i$ ($1 \le i \le n$, $y_i \in \{\texttt{0},\texttt{1}\}$) represents the target state of node $i$.

It is guaranteed that the sum of $n$ over all test cases does not exceed $2 \cdot 10^5$.

Output

For each test case, if it is impossible to make the state of every node equal to its target state, output $-1$. Otherwise, print the minimum number of energy pulses needed modulo $998\,244\,353$.

Note

In the first test case, the initial state is already equal to the target state. Therefore, no energy pulse is required, and the answer is $0$.

In the second test case, the tree contains only the root. Initially, its state is $x_1 = \texttt{0}$.

After one pulse is injected into the root, its state becomes $\texttt{1} = y_1$, and the pulse stops. Therefore, the answer is $1$.
