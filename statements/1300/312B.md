B. Archer

time limit per test

2 seconds

memory limit per test

256 megabytes

input

stdin

output

stdout

SmallR is an archer. SmallR is taking a match of archer with Zanoes. They try to shoot in the target in turns, and SmallR shoots first. The probability of shooting the target each time is ![](https://espresso.codeforces.com/a7487d7e62f90136b78ae3fbf0a008396f146e13.png) for SmallR while ![](https://espresso.codeforces.com/c443c7703e51f03d0eece0b96b9e84e425878209.png) for Zanoes. The one who shoots in the target first should be the winner.

Output the probability that SmallR will win the match.

Input

A single line contains four integers ![](https://espresso.codeforces.com/488158367221f441ba94b9475c03436069df2a7e.png).

Output

Print a single real number, the probability that SmallR will win the match.

The answer will be considered correct if the absolute or relative error doesn't exceed 10- 6.

Examples

Input

```
1 2 1 2
```

Output

```
0.666666666667
```
